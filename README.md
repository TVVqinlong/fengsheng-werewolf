# 风声谍影 · 狼人杀在线

基于网易狼人杀 **「风声谍影」** 板子的多人在线网页对局，支持 **10 人基础版** 与 **12 人进阶场**。

## 板子配置

### 10 人基础版

| 阵营 | 身份 |
|------|------|
| 狼人 | 觉醒石像鬼 ×2 |
| 好人 | 预言家、魔镜少女、熊、女巫、猎人、摄梦人、河豚、白猫 |

### 12 人风声谍影

在 10 人基础上增加：**觉醒隐狼**、**暗恋者**。

## 启动

```bash
npm install
npm start
```

浏览器打开：http://localhost:3080

## 游玩

1. 选择板子（10 / 12），输入昵称创建房间，或输入房间号加入  
2. 座位坐满并全部准备后，房主点击「开始游戏」  
3. 测试时可点「填充电脑」用机器人凑齐人数  

## 语音

对局页可点「开启语音」使用浏览器 WebRTC 联机语音（需麦克风权限）。白天为**轮流发言**：每人 1 分钟，当前发言者可点「结束发言」提前结束。

> 部分网络环境（严格 NAT）可能连不上点对点语音，可临时改用 Discord 等外置语音，游戏内发言流程仍可用。

## 技术

- Node.js + Express + Socket.IO  
- WebRTC 语音（Socket.IO 信令）  
- 纯前端静态页，房间制实时同步
